01 LaReg Regulatory Research Intern, Summer 2026 An LLM pipeline that turns energy-project dockets into structured records, built with AI agents working in parallel. run
  1. $ run lareg
  2. retrieval pull filings from Postgres and S3
  3. ocr read scanned pages with Textract
  4. extract fill the record with Gemini
  5. guards check ownership against the source
  6. merged. expanding

State utility commissions keep dockets, the case files for proposed energy projects like solar farms and transmission lines. Companies file PDFs into them, and LaReg sells the structured data buried in those PDFs. I rebuilt the pipeline that gets it out.

Every field in the record cites the page it came from. The field I spent the most time on was ownership. The model kept naming the applicant as the owner, so I added deterministic checks after extraction that blank the answer unless the cited text actually says who owns the project. I also retrained the BERT classifier that sorts each project into a subcategory.

The other half of the job was how the work got done. I ran several AI coding agents at once, each on its own piece of the pipeline, inside guardrails I set: read-only access to production data, outputs could only be added to and never overwritten, and every claim had to cite a docket number.

Python · Gemini · AWS S3 · Textract · PostgreSQL · PyTorch · Hugging Face

02 AutoPod Personal project, 2025 Type a topic, get back a finished podcast episode. run
  1. $ run autopod "why bridges sway"
  2. validate is the topic safe and doable
  3. research Claude gathers structured notes
  4. script Claude writes it for multiple hosts
  5. voice Cartesia reads every line
  6. save one MP3 to Supabase
  7. episode ready. expanding

Claude researches the topic and writes a script for multiple hosts. Every Claude call has to answer in a fixed JSON schema, so the output is always something the code can parse and the pipeline can't break on a weird response.

Each line of the script goes to Cartesia's text-to-speech API, the audio gets stitched into one MP3, and the episode is saved to Supabase so you can play your library back later.

Next.js · React · TypeScript · Node · Express · Supabase · Claude API · Cartesia
