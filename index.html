01 Co-op / LLM data pipeline LaReg An LLM pipeline that turns energy-project dockets into structured records where every field cites its source. Built with AI agents working in parallel. run
  1. $ run lareg
  2. main split the pipeline into tasks
  3. sub retrieval: Postgres and S3
  4. sub ocr: Textract on scanned pages
  5. sub extract: Gemini fills the record
  6. review check the subagents' work
  7. fix send failures back, loop
  8. passed. expanding

What I built

Utility commissions keep dockets, the case files for proposed solar farms and transmission lines, and LaReg sells the data buried in their PDFs. My pipeline pulls a docket's filings from Postgres and S3, OCRs scanned pages with Textract, and has Gemini fill a structured record where every field cites its page.

The hard part

The model kept naming the applicant as the project's owner, so deterministic checks after extraction blank the answer unless the cited text actually says who owns it. I also retrained the BERT classifier that sorts projects by type.

How I built it

A main agent split the work and spawned subagents in parallel. A reviewer subagent checked what they produced, the main agent verified it, and failures went back to the subagents to fix, looping until it passed. I set the guardrails: read-only production data, outputs that could only be added to, and every claim cited to a docket.

Python · Gemini · AWS S3 · Textract · PostgreSQL · PyTorch · Hugging Face

04 Research / Computer vision Parking lot occupancy Estimates how full mall parking lots are from satellite imagery, as a signal of economic activity. run
  1. $ run occupancy --country US
  2. sites pull malls from OpenStreetMap
  3. sample same weekday, every month
  4. frames nearest clear satellite pass
  5. read vision model fills the schema
  6. pivot mall × date matrix
  7. matrix ready. expanding

What it does

Builds a mall-by-date table of how full each parking lot was. For each date it finds the nearest clear satellite image, and a vision model reads the occupancy into a schema that Pydantic validates.

Why the same weekday

Parking depends on the day of the week more than the date, so it samples the same Thursdays every month. Every image is a paid order, so results are cached and a rerun never pays twice.
